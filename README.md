# 🚀 SkillBridge AI – Career Skill Gap Analyzer & Learning Roadmap

**SkillBridge AI** is a career-planning web application that helps learners identify skill gaps between their existing skills and their desired career roles. It analyzes skill proficiency, calculates a career readiness match percentage, highlights missing skills, and generates a personalized 7-day learning roadmap.

The platform is designed to help students and aspiring professionals understand what skills they need to develop to move closer to their career goals.

---

## ✨ Features

### 1. 🎯 Career Role Selection
Choose your desired career path from available roles:

- Frontend Developer
- Backend Developer
- AI/ML Engineer
- Data Analyst

### 2. 📋 Skill Assessment
- View the skills required for your selected career.
- Select the skills you already know.
- Compare your existing skills against the career requirements.

### 3. 📊 Skill Gap Analysis
- Analyze your current skill set.
- Calculate your career match percentage.
- Identify matched and missing skills.
- Display results in an easy-to-understand format.

**Match Percentage Formula:**

`Match Percentage = (Matched Skills / Total Required Skills) × 100`

### 4. 🗺️ Personalized 7-Day Learning Roadmap
Generate a structured 7-day roadmap based on your missing skills.

The roadmap includes:
- Learning topics for missing skills.
- Practical learning activities.
- Project-building tasks.
- Revision and practice activities.

### 5. 💾 Progress Tracking
- Mark roadmap tasks as completed.
- Track your learning progress.
- Save roadmap progress using browser local storage.
- Continue tracking progress when you revisit the application in the same browser.

## ⚙️ Installation and Setup

- Web browser (Google Chrome recommended)

```bash

```

### Step 2: Navigate to the Project

```bash
cd SkillBridgeAI
```

### Step 3: Run the Application

Open `index.html` directly in your browser.

## 🔄 How It Works

1. Open the SkillBridge AI application.
2. Select your target career role.
3. View the required skills for that role.
4. Select the skills you already know.
5. Click **Analyze My Skills**.
6. View your career match percentage.
7. Identify your matched and missing skills.
8. Generate your personalized 7-day learning roadmap.
9. Complete the recommended learning tasks.
10. Track your progress through saved roadmap activities.
